# Deploying GameRefill

## Before you deploy

1. Change the seeded admin password (`admin@meowjiofficial.com` / `ChangeMe123!`).
2. Set a strong `JWT_SECRET` in `.env` (or the host's env vars).
3. Set `NODE_ENV=production`.
4. Add your domain to Google OAuth **Authorized JavaScript origins** if you use Google login.
5. Fill in **/admin → Settings**: UPI ID, WhatsApp number, payment instructions.

---

## Option A — Render.com (free) + Neon Postgres (free)

`render.yaml` in this repo is a Render Blueprint — Render reads it and sets up the
service automatically. The database is a free Postgres on
[Neon](https://neon.tech) (Render's free filesystem is ephemeral, so SQLite would
be wiped on every restart — Postgres is required for a real shop).

1. **Create the free Neon database:**
   - Sign up at [neon.tech](https://neon.tech) → **New Project**
     (region: pick the closest to your customers, e.g. Singapore or Mumbai).
   - Open the project → **Connect** → copy the **connection string**
     (`postgres://user:password@host/dbname?sslmode=require`).
2. **Push this folder to a GitHub repo** (make sure `.env` is NOT committed).
3. In Render: **New → Blueprint** → connect the GitHub repo → **Apply**.
4. When Render prompts for env vars, paste:
   - `DATABASE_URL` → your Neon connection string (keep it private).
   - `GOOGLE_CLIENT_ID` → optional, leave blank to disable Google login.
   - `JWT_SECRET` is auto-generated by Render (no action needed).
5. Deploy. On first boot the app creates all tables in Neon and seeds
   categories, products, banners, testimonials and the admin account automatically.
6. Log in at `https://<your-app>.onrender.com/admin` and **change the admin
   password immediately** (seeded as `admin@meowjiofficial.com` / `ChangeMe123!`).
7. In **/admin → Settings**, fill in your **UPI ID**, **WhatsApp number** and
   **payment instructions** so customers can pay you.

**Free-tier realities:**
- Render's free web service **sleeps after ~15 minutes idle**; the first visit
  after sleep takes ~30–60 seconds to wake up (cold start). Keep-alive pings are
  against Render's terms — don't add them.
- Render free instances have limited monthly hours; one always-on-ish shop fits,
  but heavy traffic will exhaust it.
- Neon free tier: 0.5 GB storage, limited compute hours/month. Plenty for a new
  store; watch usage in the Neon dashboard as you grow.
- No custom domain on the cheapest path — your shop lives at
  `https://<your-app>.onrender.com` until you upgrade or point a domain at it.

## Option B — VPS with nginx (more control)

Requirements: Ubuntu 22.04+, Node 20+, nginx, a domain pointing at the server.

```bash
# 1. Install Node 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx

# 2. Copy the app
sudo mkdir -p /var/www/gamerefill
sudo chown $USER:$USER /var/www/gamerefill
# (upload the project files here, e.g. via git clone or rsync)

cd /var/www/gamerefill
cp .env.example .env
nano .env   # set JWT_SECRET, NODE_ENV=production, GOOGLE_CLIENT_ID
npm install --omit=dev

# 3. Run with systemd
sudo tee /etc/systemd/system/meowji-store.service > /dev/null <<'EOF'
[Unit]
Description=GameRefill
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/var/www/gamerefill
Environment=NODE_ENV=production
EnvironmentFile=/var/www/gamerefill/.env
ExecStart=/usr/bin/node server.js
Restart=always

[Install]
WantedBy=multi-user.target
EOF
sudo chown -R www-data:www-data /var/www/gamerefill
sudo systemctl daemon-reload
sudo systemctl enable --now meowji-store

# 4. nginx reverse proxy + HTTPS
sudo tee /etc/nginx/sites-available/meowji-store > /dev/null <<'EOF'
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
EOF
sudo ln -s /etc/nginx/sites-available/meowji-store /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 5. HTTPS with Let's Encrypt
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com -d www.your-domain.com
```

The app listens on `PORT` (default 3000). Logs: `sudo journalctl -u meowji-store -f`.
Back up `data/store.db` regularly (e.g. a nightly cron copying it off-server).

## Notes

- The app uses `better-sqlite3` (native module). `npm install` compiles it; on a VPS
  make sure build tools exist (`sudo apt install -y build-essential python3`) — usually
  only needed once.
- Static frontend is served by Express itself; no separate web server needed for files.
- `app.set('trust proxy', 1)` is already set so rate limiting and secure cookies work
  behind Render/nginx.
