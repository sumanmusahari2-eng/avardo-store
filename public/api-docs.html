Sell our products from your own website or app

The Reseller API lets you fetch our live catalogue at your tier's prices (silver), place orders programmatically, and track fulfilment — all paid from your AV COINS wallet. No manual checkout needed.

🔑
1. Get an API key

Ask us for access — we issue a key linked to your reseller account from the admin panel.

💰
2. Top up your wallet

Add AV COINS to your wallet (INR and USD wallets are separate). Every API order is prepaid from it.

📦
3. Place orders

Send orders via the API. We fulfil them (manually, or automatically where auto-fulfil is enabled).

Authentication

Send your key in the Authorization header with every request:

Authorization: Bearer mk_live_<your-key>

Keep your key secret. If it leaks, tell us and we will revoke it immediately. Rate limit: 60 requests/minute per key (HTTP 429 when exceeded).

List products

All active products with your tier prices (the tier field tells you whether your key is priced at the silver tier), variants, stock and the extra fields each product needs (e.g. Character ID). Add ?currency=USD for dollar pricing.

GET /products also GET /products/:id

# list (INR prices by default)
curl -H "Authorization: Bearer mk_live_<key>" \
  https://www.mlbbstore.in/api/v1/products

# list with USD prices
curl -H "Authorization: Bearer mk_live_<key>" \
  "https://www.mlbbstore.in/api/v1/products?currency=USD"
{
  "currency": "INR",
  "count": 23,
  "products": [{
    "id": 12,
    "name": "YouTube Premium India",
    "tier": "silver",           ← your pricing tier
    "price": 430,              ← your tier price
    "price_regular": 450,
    "in_stock": true,
    "stock": null,               ← null = unlimited
    "variants": [{ "id": 31, "name": "1 Year", "price": 430, "in_stock": true }],
    "required_fields": [{ "attribute_id": 7, "label": "Email", "type": "text" }]
  }]
}

required_fields lists what you must send in each order item's answers — for type: "select" the allowed options are included.

Place an order

The full total is debited from your wallet at your tier's prices. The order is created as paid and queued for fulfilment. If a product has variants, variant_id is required. Send the product's required_fields in answers as {attribute_id: value}.

POST /orders

curl -X POST https://www.mlbbstore.in/api/v1/orders \
  -H "Authorization: Bearer mk_live_<key>" \
  -H "Content-Type: application/json" \
  -d '{
    "currency": "INR",
    "customer": { "name": "Rahul D", "phone": "+919999999999", "email": "rahul@example.com" },
    "items": [{
      "product_id": 12,
      "variant_id": 31,
      "qty": 1,
      "answers": { "7": "rahul@example.com" }
    }]
  }'
# 201 Created
{
  "id": 1042,
  "status": "paid",
  "currency": "INR",
  "total": 430,
  "items": [{ "product_id": 12, "variant_id": 31, "variant_name": "1 Year",
                 "name": "YouTube Premium India", "qty": 1, "unit_price": 430 }]
}
Insufficient balance? You'll get HTTP 402 with need / have amounts. Top up your wallet and retry — nothing is charged on a 402.

Track orders

Order statuses: paid (queued) → delivered, or cancelled. Poll this to update your customers.

GET /orders query: ?status=paid&limit=20&page=1

GET /orders/:id

curl -H "Authorization: Bearer mk_live_<key>" \
  https://www.mlbbstore.in/api/v1/orders/1042
{
  "id": 1042,
  "status": "delivered",
  "currency": "INR",
  "total": 430,
  "delivery_note": "Invite sent to rahul@example.com",
  "created_at": "2026-10-05T09:41:00.000Z",
  "items": [{ "name": "YouTube Premium India", "variant_name": "1 Year",
                 "qty": 1, "unit_price": 430,
                 "answers": [{ "label": "Email", "value": "rahul@example.com" }] }]
}

Errors

CodeMeaning
400Bad request — the error message says exactly what's wrong (missing field, sold out, invalid variant…).
401Missing, invalid or revoked API key.
402Insufficient wallet balance — top up and retry.
404Product or order not found.
429Rate limit exceeded — slow down and retry.
